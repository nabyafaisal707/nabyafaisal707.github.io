Bug Reports

Issues identified during testing and documented with environment, severity, actual result, and analysis.

BUG-01Medium

App freezes briefly when password field receives very long input

Android 14 • Instagram app version 312.0 • Pixel 7

Actual Result

UI froze for approximately 3 seconds before displaying an error message.

Notes

Possible unoptimized validation running on the main thread for long strings.

BUG-02Low

Password field overlaps Log In button in landscape orientation

Android 14 • Instagram app version 312.0 • Pixel 7

Actual Result

Password input field visually overlapped the top of the Log In button by ~4px.

Notes

Cosmetic issue; does not block functionality, but affects visual polish.

BUG-03Low

Stale search results briefly shown after clearing search field

Android 14 • Instagram app version 312.0 • Pixel 7

Actual Result

Previous results remained visible for approximately 1 second before disappearing.

Notes

Likely a missing state reset tied to the clear button action.

BUG-04Medium

Search results briefly show results for a previous query during rapid typing

Android 14 • Instagram app version 312.0 • Pixel 7

Actual Result

Results for an earlier query flashed briefly before updating to the correct results.

Notes

Suggests a possible race condition between overlapping search API calls; request cancellation or debounce logic recommended.
